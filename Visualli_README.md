# 🌟 Visualli Engineering Challenges

This repository hosts the challenge briefs used as part of the Visualli engineering evaluation process.

Candidates may attempt **one** challenge or **both** challenges, depending on their strengths and the role being assessed. A strong, well-executed submission on one challenge is better than two rushed submissions.

## 🎯 Challenge Options

- 🧠 [AI Challenge](./ai-challenge.md)  
  Focuses on AI engineering, structured LLM output, validation, backend API basics, and frontend rendering of generated data.

- 🧩 [Fullstack Challenge](./fullstack-challenge.md)  
  Focuses on frontend performance, backend query design, persistence, and building responsive product behavior end to end.

## 📦 Submission Guidance

- Read the full challenge brief before you begin.
- Submit a **public repository URL** for your solution.
- Commit at logical milestones so the evolution of your solution is visible.
- If you attempt both challenges, make sure each one is clearly organized into sub-folders in your repository.

## 🧭 Recommendation

- 🧠 If your strengths are in AI engineering, prompt design, LLM selection, fine-tuning, schema validation, and model-output handling, start with the AI challenge.
- 🧩 If your strengths are in product engineering, rendering performance, API design, and data flow, start with the full-stack challenge.

## 📊 Evaluation

- ✅ scope and expectations
- 📈 evaluation criteria
- 📝 submission deliverables
